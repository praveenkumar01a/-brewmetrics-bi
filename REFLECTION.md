

Working on the BrewMetrics BI project helped me understand how Business Intelligence development can be combined with AI assistance and version control. GitHub Copilot was useful while creating DAX measures because it provided initial suggestions for calculations such as month-over-month growth, running totals, and product ranking. However, I did not use the generated formulas blindly. I checked the table names, relationships, filter context, and output before using each measure.

Some Copilot suggestions required correction or modification. In particular, I had to make sure that the measures used the correct dimension tables and that calculations matched the actual columns available in the dataset. This showed me that AI-generated code still needs to be tested and understood by the developer.

Using GitHub also changed the way I approached the project. Instead of creating the entire Power BI report first and uploading it at the end, I developed the solution incrementally. I committed the star schema first, followed by each DAX measure and then the dashboard. This made the development process easier to track and allowed each change to have a clear purpose.

Overall, the project showed me that Copilot can speed up development, while GitHub provides traceability and accountability for the work.
